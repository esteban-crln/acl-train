Masque générique

Masque générique = 255.255.255.255 − masque réseau. Un bit à 0 doit correspondre, un bit à 1 est libre.

PréfixeMasqueGénérique
/32255.255.255.2550.0.0.0 = host
/30255.255.255.2520.0.0.3
/24255.255.255.00.0.0.255
/22255.255.252.00.0.3.255
/16255.255.0.00.0.255.255
/00.0.0.0255.255.255.255 = any

Comment Ro traite un paquet

  1. Les lignes sont lues dans l'ordre. La première qui correspond s'applique, les suivantes sont ignorées.
  2. Si aucune ne correspond : deny implicite. Pour tout autoriser par défaut : permit any ou permit ip any any.
  3. Une seule ACL par protocole (IPv4/IPv6), par sens et par interface.
  4. Sens IN : ACL, puis redirection de ports. L'ACL voit encore 200.0.0.254.
  5. Sens OUT : NAT, puis ACL. Sur S0/0, l'ACL voit déjà la source 200.0.0.254.
  6. Une ACL appliquée mais inexistante laisse tout passer.
  7. Règle d'or : mettre en place les ACL une par une et tester à chaque fois.

weekdays lundi-vendredi · weekend samedi-dimanche · daily tous les jours · jours en anglais (monday…). Hors plage, la règle est ignorée : le paquet passe aux lignes suivantes.

Les réponses : sans état et avec état

Sans état, chaque paquet est jugé seul. Pour laisser revenir les réponses :

permit tcp any 172.16.0.0 0.0.255.255 established
permit icmp any 172.16.0.0 0.0.255.255 echo-reply

Avec état (CBAC), on inspecte dans le sens des requêtes ; les réponses sont acceptées dans l'autre sens sur la même interface, même si une ACL les interdit :

Ro(config)# ip inspect name LEGITIME tcp
Ro(config)# ip inspect name LEGITIME udp
Ro(config)# ip inspect name LEGITIME icmp
Ro(config)# interface S0/0
Ro(config-if)# ip inspect LEGITIME out

FTP : privilégier le mode passif avec un filtrage avec état.

NAT/PAT et redirection

Ro(config-if)# ip nat inside        ! G0/0, G0/1.x
Ro(config-if)# ip nat outside       ! S0/0
Ro(config)# ip access-list standard NAT
Ro(config-std-nacl)# permit 172.16.0.0 0.0.255.255
Ro(config)# ip nat inside source list NAT interface S0/0 overload
Ro(config)# ip nat inside source static tcp 172.17.0.1 443 200.0.0.254 443

La PAT fait sortir tous les réseaux privés avec l'IP de S0/0. La redirection de ports publie un serveur privé sur un port de l'IP publique.

Filtrage par niveau de sécurité

0Internet, aucune confiance
50DMZ, confiance partielle
100LAN, forte confiance

Permit implicite vers une zone de confiance plus faible ou égale, deny implicite vers une zone plus forte. L'inspection est active par défaut. Tout le reste se règle par ACL (par exemple ouvrir Internet → DMZ en 443).
